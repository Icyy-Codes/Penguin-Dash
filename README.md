# Penguin-Dash
A 2d game where a little penguin runs and slides through ice.

Hello this was probably one of the most tiring game i ever built.
And here i will tell you everything i have done to make this game.

This came from just a random thought. I started making this game just to see where it goes.
As i went on to making this game i gave in more and more time from the day of beginning this project.

I used youtube and google to learn new things to make this game.

I rushed through google and many sprite sites to find the perfect one.
But for the ground level images i wasn't able to get all the images i desired, so i used ai to make changes to present images and make the ones i recuired.
Also i had to edit the sprite sheet of for 1-2 sprites for the game.

After the hectic rush to setup the grounds, backgrounds and sprites i coded different parts of the project.
To be honest I used ai to get help when things went wrong and many things crashed. Don't tell me you don't use ai to find your mistakes.

Lastly I added the finishing touches like the main menu and game over screens.
Finally i completed my project.

Though this readme file is short, it took me a lot of time and headache to make this game.
Hope you enjoy it :)
